Japanese Word Kitchen

Technical blueprint review companion

This app is a single-device browser experience: the learner opens a cozy restaurant home, studies a few Japanese vocabulary cards, earns ingredients for a dish, and returns to a calm home view with the missed-words tray ready for later review.

Core journey

1. Home The learner chooses study, vocabulary, or review.
2. Session Three dish cards are selected and populated with words.
3. Study The learner flips each card and rates it 1–4.
4. Progress 3–4 earns an ingredient; 1–2 sends it to missed words.
5. Finish Each dish reveals a final illustration and a cultural fact.
6. Return The app sends the learner back to home, with saved state intact.

Key components

  • Restaurant home and navigation
  • Vocabulary manager
  • Study session engine
  • Tabletop card flow
  • Dish reveal and cultural fact view
  • Missed-word review flow
  • Browser storage persistence

Important design decisions

  • Single-page browser app for the prototype.
  • Custom data stored in browser localStorage, not a backend.
  • No user accounts or cross-device sync. This matches the POC boundary.
  • Predetermined dish illustrations keyed to earned ingredient counts.
  • Original cozy artwork: Heian-inspired paper and ink, with gentle whimsy, natural warmth, and expressive hand-drawn animation as broad mood cues. Studio Ghibli is an inspiration reference only; no recognizable characters, settings, or film imagery are reproduced.
